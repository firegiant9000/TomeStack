The Microsoft Edge WebView2 **Runtime** is not redistributed. It is a system component that is preinstalled on Windows 11 or installed by the user. The UI uses system fonts and ships no fonts or icon sets.

**No Windows SDK file ships (2026-10-27, release checklist §2 option (b)):** up to 0.7.1 the worker shipped Microsoft's projection assemblies `Microsoft.Windows.SDK.NET.dll` and `WinRT.Runtime.dll` under the Windows SDK license, with end-user terms in this file. From the next release, C#/WinRT compiles the projection the worker needs into the worker itself, so neither file ships and those terms are no longer needed. **Build time only:** the projection is generated from the Windows 10 2004 API metadata in the NuGet package `Microsoft.Windows.SDK.Contracts` 10.0.19041.2, which is under the Windows SDK license (https://aka.ms/WinSDKLicenseURL). No Microsoft file from that package ships. The generated projection compiled into the worker contains the API names, signatures and interface IDs from that metadata, which any program calling these Windows APIs has to contain; the SDK license's terms may still apply to it and to building TomeStack, as recorded in [docs/licensing/release-checklist.md](docs/licensing/release-checklist.md).
